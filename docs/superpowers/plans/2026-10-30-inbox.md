# Decision inbox Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A second liveview view, `/inbox`, that lists every question a workstream is waiting on the owner to answer, oldest first, each with its options, the files on its branch worth looking at, and a link that opens the session.

**Architecture:** The band writes two more fields into its session file (`options`, `waitingSince`). The liveview's `sources.mjs` lists the committed files a branch adds or changes (`branchFiles`), `snapshot.mjs` adds an `inbox` list to the snapshot, and `server.mjs` serves `page.html` at `/inbox` too, plus `/api/file`, which serves file `n` of a waiting session's list and nothing else. `page.html` picks its view from `location.pathname`.

**Tech Stack:** Node 18 or newer (`node:http`, `node:test`, `node:child_process`), git, vanilla HTML, CSS and JS; the band mod in TSX on the `claude-code` engine. No dependencies, no build step.

**Spec:** `docs/superpowers/specs/2026-10-30-inbox-design.md`

**Approved look:** `docs/superpowers/specs/liveview/inbox-prototype.html`, with `inbox-dark-1440.jpg` and `inbox-dark-390.jpg` beside it. Task 5 copies its CSS and render code, adapted to real data.

## Global Constraints

- **Node:** Node 18 or newer. No npm dependencies, no build step; the liveview stays zero-dependency. Liveview tests run from `plugins/orchestra/liveview` with `node --test tests/*.test.mjs` (a bare `tests/` also picks up `tests/demo.mjs`, which starts a server).
- **Band tests:** from `plugins/orchestra`, `claude plugin test .`; validation `claude plugin validate .`.
- **Session file:** stays `v: 1`. It gains `options` (the labels of the open `AskUserQuestion`'s first question, in order; `[]` when there is none or the wait comes from the `Status:` line) and `waitingSince` (ISO time the state last became `waiting`; `null` while not waiting; kept across rewrites while the state stays `waiting`). `detail` keeps its current text.
- **Branch files:** `git diff <integration>...HEAD` in the worktree, the integration ref resolved origin first; committed files only. Kept: added (`A`) or modified (`M`) images (`png`, `jpg`, `jpeg`, `gif`, `webp`, `svg`), `pdf`, `html`, or `md` under `docs/superpowers/specs/` or `docs/superpowers/plans/`. Kinds: `Mockup`, `Screenshot`, `Image`, `PDF`, `Page`, `Spec`, `Plan`; changes: `added`, `changed`. Order: pictures, pages, PDFs, specs, plans, each by path. Cached per worktree while `HEAD` does not move.
- **Inbox:** one entry per session file in `waiting` state, oldest `waitingSince` first, a missing one last. `stale` past 30 minutes (the band's rule). A PR links when it is an `https://` URL, or `#N` with an `origin` remote on `github.com`; otherwise it is text; `none` or empty gives no PR.
- **File route:** `GET /api/file?s=<session id>&n=<index>`. No path ever comes from the request. Unknown session or index: 404. Committed content at `HEAD`, capped at 20 MB (413 above). `md` is `text/plain; charset=utf-8`. `html` and `svg` get `Content-Security-Policy: sandbox allow-scripts`; every file gets `X-Content-Type-Options: nosniff` and `cache-control: no-store`. The `Host` check (403) applies.
- **Page:** the prototype is the reference for every value it shows. One column below 900px (ask, evidence, button); the phone bar below 640px. Index above 4 questions; at most 2 pictures and 5 file rows per card; the wait in vermilion past 2 hours. The 5-second poll, "Stale since", the offline line and the theme in `localStorage` work as on the overview. Nothing is answered from the page: options are text, never buttons.
- **Repository rules:**
  - English everywhere. No em dashes.
  - No confidential content: no client, brand, people or server names, emails, credentials or paths from other repositories. Demo data stays made up.
  - Comments say only the why, in the surrounding code's density.
  - Commit with `git add <path>` only, never `git add -A`, and check `git diff --cached --stat` first. Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - Before any commit: `git fetch` and rebase on `origin/main`, because other sessions push to this repository.

const PICTURE = /\.(png|jpe?g|gif|webp|svg)$/i

// Kind and sort rank of a file worth looking at before answering: pictures, pages, PDFs, specs, plans. null for the rest.
function fileKind(p) {
  const low = p.toLowerCase()
  // A mockup or screenshot can be a picture, a page or a PDF; a spec or plan keeps its own kind.
  const named = low.includes('mockup') ? 'Mockup' : low.includes('screenshot') ? 'Screenshot' : null
  if (PICTURE.test(low)) return [named ?? 'Image', 0]
  if (low.endsWith('.html')) return [named ?? 'Page', 1]
  if (low.endsWith('.pdf')) return [named ?? 'PDF', 2]
  if (!low.endsWith('.md')) return null
  if (p.startsWith(`${SPECS}/`)) return ['Spec', 3]
  if (p.startsWith(`${PLANS}/`)) return ['Plan', 4]
  return null
}

// The files a workstream's branch committed that the owner may look at, reused while HEAD does not move.
const filesCache = new Map()
export function branchFiles(worktree, integration) {
  const head = git(worktree, ['rev-parse', 'HEAD'])?.trim()
  if (!head) return []
  const key = `${worktree}|${integration}`
  if (filesCache.get(key)?.head === head) return filesCache.get(key).files
  const base = integrationRef(worktree, integration)
  // -z keeps unusual paths unquoted; --no-renames lists a renamed file as added, so it is kept.
  const out = base ? git(worktree, ['diff', '-z', '--no-renames', '--name-status', '--diff-filter=AM', `${base}...HEAD`]) : null
  const parts = (out ?? '').split('\0')
  const ranked = []
  for (let i = 0; i + 1 < parts.length; i += 2) {
    const k = fileKind(parts[i + 1])
    if (k) ranked.push([k[1], { path: parts[i + 1], kind: k[0], change: parts[i] === 'A' ? 'added' : 'changed', picture: PICTURE.test(parts[i + 1]) }])
  }
  const files = ranked.sort((a, b) => a[0] - b[0] || (a[1].path < b[1].path ? -1 : a[1].path > b[1].path ? 1 : 0)).map(r => r[1])
  if (out !== null) filesCache.set(key, { head, files })
  return files
}

// The inbox: every question a session waits on the owner to answer, oldest first, as the server sorts them.
const FILES_SHOWN = 5
const qid = s => `q-${s.replace(/[^A-Za-z0-9_-]/g, '_')}`
const mins = t => Math.max(0, Math.round((Date.now() - t) / MIN))
const waited = t => { const m = mins(t); return m >= 60 ? `${Math.floor(m / 60)} h ${m % 60} m` : `${m} m` }
const spoken = t => { const m = mins(t), h = Math.floor(m / 60), r = m % 60; return [h && `${h} hour${h > 1 ? 's' : ''}`, r && `${r} minute${r > 1 ? 's' : ''}`].filter(Boolean).join(' ') || 'less than a minute' }
const lag = t => (mins(t) >= 60 ? waited(t) : `${mins(t)} min`)
const long = q => q.since != null && Date.now() - q.since > 2 * HOUR
const fileName = p => p.split('/').pop()
const fileUrl = (q, f) => `/api/file?s=${encodeURIComponent(q.session)}&n=${f.n}`

// Opened cards, per session and waitingSince, so a reload keeps them and a new question does not inherit one.
let opened = new Set()
try { opened = new Set(JSON.parse(sessionStorage.getItem('inbox-opened') || '[]')) } catch { /* private window */ }
const openedKey = q => `${q.session}|${q.since}`
const markOpened = q => { opened.add(openedKey(q)); try { sessionStorage.setItem('inbox-opened', JSON.stringify([...opened])) } catch { /* private window */ } }

// Thumbnails are kept across redraws: the file route is no-store, so a new <img> would download again every 5 seconds.
// shortcut: a picture changed in a new commit under the same path shows after a reload; key on the commit if that matters.
const thumbs = new Map()
const thumb = (q, f) => {
  const key = `${q.session}|${f.n}|${f.path}`
  if (!thumbs.has(key)) thumbs.set(key, $('img', { src: fileUrl(q, f), alt: `${f.kind} ${fileName(f.path)}, opens in a new tab`, loading: 'lazy' }))
  return thumbs.get(key)
}

function offers(q) {
  if (!q.options.length) return $('p', { class: 'opts' }, 'No options offered: it needs your own words.')
  // Up to three read as one sentence; more become a list.

  return $('p', { class: 'opts' }, 'It offers ', ...q.options.flatMap((o, i) => [i ? (i === q.options.length - 1 ? ', or ' : ', ') : '', $('b', {}, o)]), '.')
}

      more > 0 ? $('li', {}, $('span', { class: 'kind' }, ''), $('span', { class: 'chg' }, `${more} more on the branch`), '') : null,
