# Band mod Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A band above the prompt in every session with orchestra installed. It shows plan limits, burn pace and the workstreams that need the owner, opens sessions and the liveview from the band, and keeps the prompt cache warm while subagents run.

**Architecture:** A hooks module inside the orchestra plugin. Each session's copy of the mod writes its own `.orchestra/sessions/<id>.json` in the main checkout. Every copy reads the folder on a 20-second timer, builds a view with pure functions in `logic.ts`, stores the view in `$.state` and draws it in the `AbovePrompt` slot, beneath any band another mod draws there. The same timer sends a keep-warm `$.model.fork` while one of the session's own subagents runs.

**Tech Stack:** The Claude Code mod API (`claude-code` module, `claude-code/testing`), TypeScript and TSX, `claude plugin validate`, `claude plugin test`, `tsc`.

**Spec:** `docs/superpowers/specs/2026-10-30-band-mod-design.md`

## Global Constraints

- The mod ships inside the orchestra plugin. If Task 1 shows that an older Claude Code or `claude -p` fails to load orchestra because of the module, stop and report: the mod then moves to its own `orchestra-band` plugin, which needs a new plan.
- The mod costs no LLM tokens except the keep-warm pings, which it counts and shows.
- Settings: `cacheMinutes` default 60, `warmMaxHours` default 2.
- Thresholds: context row at 250k tokens or more; stale after 30 minutes without an update; refresh every 20 seconds.
- Outside an orchestra project (not a git repository, or no `.orchestra/` folder in the main checkout) the mod writes nothing and shows the limits line only.
- The mod never shows ponytail controls and always draws `next(e)` beneath its own band.
- The `Liveview` button opens only `http` or `https` URLs on `localhost` or `127.0.0.1`.
- English everywhere. No em dashes. No confidential content: no client, brand, people or server names, emails, credentials or paths from other repositories.
- Commit with `git add <path>` only, never `git add -A`, and check `git diff --cached --stat` first. Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Before any commit: `git fetch` and rebase on `origin/main`, because other sessions also push to this repository.

```ts
import type { Register } from 'claude-code'

export const register: Register = on => {
  on('session.start', async ($, e, next) => {
    const result = await next(e)
    const log = async (line: string) => {
      const file = `${await $.session.root()}/spike.log`
      const old = await $.fs.read(file).catch(() => '')
      await $.fs.write(file, `${old}${new Date(await $.clock.now()).toISOString()} ${line}\n`)
    }
    // Check 1: does the timer fire while the session is idle?
    $.clock.every(60_000, () => void log('tick'))
    // Check 2: can the mod reach the app's session server? Try the likely names.
    for (const server of ['ccd_session_mgmt', 'ccd-session-mgmt', 'Claude session management']) {
      const r = await $.mcp.call(server, 'get_session', { session_id: 'self' }).catch((err: unknown) => ({ error: String(err) }))
      await log(`mcp ${server}: ${JSON.stringify(r).slice(0, 300)}`)
    }
    return result
  })
  on('command.run', async ($, e, next) => {
    if (e.command !== 'spike-fork') return next(e)
    // Check 3: a fork outside a turn, and whether it read the main cache.
    const r = await $.model.fork({ prompt: 'Reply with: ok' })
    const usage = 'usage' in r ? r.usage : undefined
    return { text: `fork: answered=${r.isAnswered} usage=${JSON.stringify(usage)}` }
  })
  on('session.start', async ($, e, next) => {
    await $.command.register({ name: 'spike-fork', description: 'orchestra spike: fork once' })
    return next(e)
  })
}
```

```ts
import type { BandRow, BandView, Limit, RegistryRow, Role, SessionFile, State, StatusLine } from './types'

export const CONTEXT_LIMIT = 250_000
export const STALE_MS = 30 * 60_000
export const REFRESH_MS = 20_000

// Forward slashes, no trailing slash, lowercase drive letter: paths from git, the registry and the engine compare equal.
export function norm(path: string): string {
  const p = path.trim().replace(/\\/g, '/').replace(/\/+$/, '')
  return /^[A-Za-z]:/.test(p) ? p[0]!.toLowerCase() + p.slice(1) : p
}

// A worktree's .git is a file: "gitdir: <main>/.git/worktrees/<name>". null means .git is a folder (the main checkout).
export function mainCheckout(root: string, gitFile: string | null): string {
  if (gitFile === null) return norm(root)
  const dir = /^gitdir:\s*(.+)$/m.exec(gitFile)?.[1]
  const at = dir === undefined ? -1 : norm(dir).indexOf('/.git/worktrees/')
  return at < 0 ? norm(root) : norm(dir!).slice(0, at)
}

// Rows of .orchestra/workstreams.md: | name | session | `branch` at `path` | ...
export function parseRegistry(md: string): RegistryRow[] {
  return md.split('\n').flatMap(line => {
    const cells = line.split('|').slice(1, -1).map(c => c.trim())
    const worktree = /at `([^`]+)`/.exec(cells[2] ?? '')?.[1]
    return cells[0] && worktree && cells[0] !== 'Workstream' ? [{ workstream: cells[0], worktree: norm(worktree) }] : []
  })
}

export function roleOf(root: string, main: string, rows: RegistryRow[]): { role: Role; workstream: string | null } {
  const r = norm(root)
  if (r === norm(main)) return { role: 'orchestrator', workstream: null }
  const row = rows.find(x => x.worktree === r)
  return row ? { role: 'workstream', workstream: row.workstream } : { role: 'unregistered', workstream: null }
}

// "Status: <running | idle | waiting on owner> · context <N>k · <stage> · PR <...> · waiting on: <...> · updated <...>"
export function parseStatus(note: string): StatusLine | null {
  const line = /^Status:\s*(.+)$/m.exec(note)?.[1]
  if (line === undefined) return null
  const parts = line.split(' · ').map(p => p.trim())
  const head = parts[0] ?? ''
  const state: State | null = head.startsWith('waiting') ? 'waiting' : head === 'running' ? 'running' : head === 'idle' ? 'idle' : null
  const pr = parts.find(p => p.startsWith('PR '))?.slice(3) ?? ''
  const waiting = parts.find(p => p.startsWith('waiting on:'))?.slice('waiting on:'.length).trim() ?? ''
  const stage = parts.slice(1).find(p => !/^(context |PR |waiting on:|updated )/.test(p)) ?? ''
  return { state, stage, pr, waitingOn: waiting === 'none' ? '' : waiting }
}

export function parseSessionFile(text: string): SessionFile | null {
  try {
    const f = JSON.parse(text) as SessionFile
    return f && f.v === 1 && typeof f.session === 'string' ? f : null
  } catch {
    return null
  }
}

// shortcut: uses the week's average burn rate, not the last few hours; switch to recent samples kept in the session files if the projection proves misleading.
export function runOut(limit: Limit | undefined, now: number): number | null {
  if (!limit?.resetsAt || limit.percentUsed <= 0) return null
  const resets = Date.parse(limit.resetsAt)
  const elapsed = now - (resets - 7 * 86_400_000)
  if (!(elapsed > 0)) return null
  const at = now + ((100 - limit.percentUsed) * elapsed) / limit.percentUsed
  return at < resets ? Math.round(at) : null
}

export const fmtK = (tokens: number | null) => (tokens === null ? '?' : `${Math.max(1, Math.round(tokens / 1000))}k`)
export const age = (ms: number) => (ms >= 3_600_000 ? `${Math.floor(ms / 3_600_000)}h` : `${Math.floor(ms / 60_000)}m`)

export function isLocalUrl(url: string): boolean {
  try {
    const u = new URL(url)
    return (u.protocol === 'http:' || u.protocol === 'https:') && (u.hostname === 'localhost' || u.hostname === '127.0.0.1')
  } catch {
    return false
  }
}

export function openerArgv(os: 'windows' | 'mac' | 'linux', target: string): string[] {
  return os === 'windows' ? ['cmd', '/c', 'start', '', target] : [os === 'mac' ? 'open' : 'xdg-open', target]
}

export type ViewInput = {
  inProject: boolean
  role: Role
  self: string
  files: SessionFile[]
  registry: RegistryRow[]
  now: number
  liveview: string
  ownLimits?: Limit[]
}

const pct = (limits: Limit[], kind: string) => limits.find(l => l.kind === kind)?.percentUsed ?? null

export function buildView(i: ViewInput): BandView {
  const fresh = [...i.files].filter(f => f.limits.length > 0).sort((a, b) => b.updatedAt.localeCompare(a.updatedAt))[0]
  const limits = fresh?.limits ?? i.ownLimits ?? []
  const view: BandView = {
    inProject: i.inProject,
    fiveHour: pct(limits, 'five_hour'),
    week: pct(limits, 'seven_day'),
    runOut: runOut(limits.find(l => l.kind === 'seven_day'), i.now),
    running: 0,
    waiting: 0,
    rows: [],
    liveview: isLocalUrl(i.liveview) ? i.liveview : '',
  }
  if (!i.inProject) return view

  const latest = (ws: string) => i.files.filter(f => f.workstream === ws).sort((a, b) => b.updatedAt.localeCompare(a.updatedAt))[0]
  const open = i.registry.map(r => ({ ws: r.workstream, f: latest(r.workstream) }))
  view.running = open.filter(o => o.f?.state === 'running').length
  view.waiting = open.filter(o => o.f?.state === 'waiting').length
  const row = (f: SessionFile, name: string, shape: BandRow['shape'], reason: string, detail: string): BandRow =>
    ({ key: f.session, name, link: f.link, shape, reason, context: fmtK(f.context.tokens), detail })

  if (i.role === 'workstream') {
    const me = i.files.find(f => f.session === i.self)
    if (me) {
      const big = (me.context.tokens ?? 0) >= CONTEXT_LIMIT
      const shape = me.state === 'waiting' ? 'triangle' : big ? 'square' : 'circle'
      view.rows = [row(me, me.title || me.workstream || me.branch, shape, me.stage || me.state, me.warm.pings > 0 ? `warm ${me.warm.pings}x` : '')]
    }
    return view
  }

  for (const { ws, f } of open) {
    if (f === undefined) {
      view.rows.push({ key: `none-${ws}`, name: ws, link: '', shape: 'half', reason: 'stale', context: '?', detail: 'no report yet' })
      continue
    }
    const name = f.title || ws
    const old = i.now - Date.parse(f.updatedAt)
    if (f.state === 'waiting') view.rows.push(row(f, name, 'triangle', 'waiting on you', f.detail))
    else if ((f.context.tokens ?? 0) >= CONTEXT_LIMIT) view.rows.push(row(f, name, 'square', 'over 250k', 'clear at wave end'))
    else if (old > STALE_MS) view.rows.push(row(f, name, 'half', 'stale', `stale · ${age(old)}`))
  }
  for (const f of i.files) {
    if (f.role === 'unregistered' && i.now - Date.parse(f.updatedAt) <= STALE_MS) {
      view.rows.push(row(f, `unregistered ${f.branch}`, 'half', 'unregistered', 'not in .orchestra/workstreams.md'))
    }
  }
  return view
}

export type PingInput = {
  now: number
  lastRequestAt: number
  cacheMinutes: number
  warmMaxHours: number
  youngestRunningSince: number | null
}

export function pingDue(p: PingInput): boolean {
  if (p.youngestRunningSince === null || p.now - p.youngestRunningSince > p.warmMaxHours * 3_600_000) return false
  const margin = p.cacheMinutes <= 5 ? 30_000 : 60_000
  return p.now >= p.lastRequestAt + p.cacheMinutes * 60_000 - margin
}
```

```tsx
export async function writeReport($: EngineInterface) {
  if (ctx.main === null) return
  const status = ctx.workstream ? parseStatus((await read$($, `${ctx.root}/docs/workstreams/${ctx.workstream}.md`)) ?? '') : null
  const state = ctx.question ? 'waiting' : ctx.turn ? 'running' : status?.state === 'waiting' ? 'waiting' : 'idle'
  const file: SessionFile = {
    v: 1, session: ctx.id, role: ctx.role, workstream: ctx.workstream, branch: ctx.branch, title: ctx.title, link: ctx.link,
    state, detail: ctx.question || (state === 'waiting' ? (status?.waitingOn ?? '') : ''), stage: status?.stage ?? '', pr: status?.pr ?? '',
    context: ctx.context, limits: ctx.limits, warm: { pings: ctx.pings, last: ctx.lastPing },
    updatedAt: new Date(await $.clock.now()).toISOString(),
  }
  await $.fs.write(`${ctx.main}/.orchestra/sessions/${ctx.id}.json`, JSON.stringify(file))
}

// Re-reads the reports when a file changed since the last pass, then stores the view.
async function refresh($: EngineInterface, force = false) {
  const dir = `${ctx.main}/.orchestra/sessions`
  const entries = ctx.main === null ? [] : await $.fs.list(dir).catch(() => [])
  const stamp = entries.map(f => `${f.name}:${f.mtimeMs}`).join(',')
  if (!force && stamp === ctx.stamp) return
  ctx.stamp = stamp
  const files = (await Promise.all(entries.filter(f => f.name.endsWith('.json')).map(f => read$($, `${dir}/${f.name}`))))
    .flatMap(t => (t === null ? [] : [parseSessionFile(t)].filter((f): f is SessionFile => f !== null)))
  const registry = ctx.main === null ? [] : parseRegistry((await read$($, `${ctx.main}/.orchestra/workstreams.md`)) ?? '')

    liveview = ''
```

```tsx
// Every REFRESH_MS: redraw when a report changed, and keep the cache warm while one of this session's subagents runs.
async function tick($: EngineInterface, options: Readonly<Record<string, unknown>>) {
  await refresh($)
  const now = await $.clock.now()
  const agents = await $.agent.list().catch(() => [])
  const running = agents.filter(a => a.status === 'running' || a.status === 'pending')
  for (const a of running) if (!ctx.seen.has(a.id)) ctx.seen.set(a.id, now)
  for (const id of [...ctx.seen.keys()]) if (!running.some(a => a.id === id)) ctx.seen.delete(id)
  const youngest = ctx.seen.size === 0 ? null : Math.max(...ctx.seen.values())
  const due = pingDue({
    now,
    lastRequestAt: ctx.lastRequestAt,
    cacheMinutes: Number(options.cacheMinutes ?? 60),
    warmMaxHours: Number(options.warmMaxHours ?? 2),
    youngestRunningSince: youngest,
  })
  if (!due) return
  ctx.lastRequestAt = now
  const r = await $.model.fork({ prompt: 'Reply with: ok' }).catch(() => undefined)
  if (r?.isAnswered) {
    ctx.pings += 1
    ctx.lastPing = new Date(now).toISOString()
    await writeReport($)
  }
}
```

```markdown
## The band

orchestra draws a band above the prompt in every session. In an orchestra project the orchestrator's band shows the 5-hour and weekly plan limits, when the week runs out at the current pace, how many workstreams are running, and one row for each workstream that needs you: waiting on an answer, over 250k tokens of context, or gone quiet. In the desktop app a row's name opens that session, and a `Liveview` button opens the local dashboard while it runs. A workstream session shows the same summary and its own row. In other projects the band shows the limits line only.

Each session writes its own report to `.orchestra/sessions/` (not versioned) after each turn; the band re-reads the folder every 20 seconds. Staying live costs no tokens.

**Keep-warm.** While one of a session's own subagents runs, the band sends a one-line request just before the prompt cache would expire, so the session does not pay to write its whole context to the cache again when the subagent returns. A cache read costs about 0.1x the input price; rewriting an expired cache costs 1.25x (5-minute cache) or 2x (1-hour cache). How cache reads count against plan limits is not published. Two settings, in the plugin's config menu:

- `cacheMinutes` (default 60): your cache lifetime. Use 5 for API keys and overage.
- `warmMaxHours` (default 2): stop keeping the cache warm for a subagent that has run this long.

The band shares its slot with other mods. ponytail's band stays as it is, with its own level switch. ponytail's level is one flag for every session (`~/.claude/.ponytail-active`): switching it in one session switches all of them, while each orchestra agent's per-stage mode stays in its own prompt.
```
