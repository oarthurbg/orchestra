# Liveview dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A localhost page for one orchestra project, kept open beside Claude Code. It shows the plan limits with a projection, what needs the owner, and each workstream's progress, ETA and timeline. It uses zero LLM tokens.

**Architecture:** Zero-dependency Node in `plugins/orchestra/liveview/`:

- `sources.mjs` reads session files, the registry, handoff notes, plans, git and transcripts.
- `snapshot.mjs` turns them into one JSON snapshot with pure functions.
- `server.mjs` serves `page.html` and `/api/snapshot` on `127.0.0.1` and rebuilds every 5 seconds. It writes `.orchestra/liveview.json` for the band.
- The band starts the server in maestro sessions, and `/orchestra:liveview` starts and stops it by hand.

**Tech Stack:** Node 18 or newer (`node:http`, `node:test`, `node:child_process`), git, vanilla HTML, CSS and JS. No dependencies, no build step.

**Spec:** `docs/superpowers/specs/2026-10-30-liveview-design.md`

**Approved look:** the page in Task 4 is the prototype the owner approved from screenshots, built with taste-skill (`achromatic-ledger`, seed 1286254319, `--keep palette,type`), checked with `inspect.mjs --app` (0 FAIL), Playwright and impeccable's critique.

## Global Constraints

- **Node:** Node 18 or newer. No npm dependencies, no build step. Tests run with `node --test <files>`; list the files, because `node --test <folder>` does not work on every Node version.
- **Runtime cost:** the dashboard costs no LLM tokens. It never writes to sessions, plans or git; under the project it writes only `.orchestra/liveview.json` and `.orchestra/eta-history.jsonl`.
- **Network:** the server binds `127.0.0.1` only. It refuses any `Host` header other than `localhost:<port>` or `127.0.0.1:<port>` with 403, and answers only `GET`.
- **Ports:** first port 4317, then the next 20. Rebuild every 5 seconds. Idle exit after 30 minutes with no fresh session file.
- **Contracts with the band:**
  - It reads `.orchestra/sessions/*.json` with `v: 1` (band spec).
  - It writes `.orchestra/liveview.json` = `{ "url": "http://localhost:<port>/", "pid": <pid> }`; the band reads only `url`.
  - Do not change the band's spec or plan files.
- **ETA:** gaps capped at 120 minutes. An estimate needs at least 3 past tasks in its bucket, otherwise 45 minutes, marked uncalibrated. A queued workstream with no history lasts 2 days.
- **Token weights:** input 1, cache write 1.25, cache read 0.1, output 5, times the model weight: Opus 5, Sonnet 3, Haiku 1.
- **Transcripts:** read only `timestamp`, `message.model`, `message.id` and `message.usage`; never keep or show message content.
- **Repository rules:**
  - English everywhere. No em dashes.
  - No confidential content: no client, brand, people or server names, emails, credentials or paths from other repositories. Demo data stays made up.
  - Commit with `git add <path>` only, never `git add -A`, and check `git diff --cached --stat` first. Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - Before any commit: `git fetch` and rebase on `origin/main`, because other sessions push to this repository.
- **Order:** Task 6 needs the band mod merged (`plugins/orchestra/hooks/band/register.tsx` and `tests/band.test.tsx` exist on `main`). Tasks 1 to 5 do not.

  - Parsing:
    - `parseRegistry(md) -> [{ name, session, branch, worktree, stage }]`
    - `planPathFromNote(note) -> string | null`
    - `parsePlan(md) -> [{ n, title, agent, risk, steps, done }]`
    - `parseBranches(claudeMd) -> { integration, production }`
    - `parseQueued(handoff) -> string[]`
  - Timing and ETA:
    - `median(xs)`
    - `cappedMinutes(from, to, commits)`
    - `timedTasks(plan, versions, commits) -> [{ plan, task, agent, risk, startedAt, finishedAt, minutes }]`
    - `estimate(task, history) -> { minutes, calibrated }`
    - `typicalWorkstream(history) -> { minutes, calibrated }`
  - Tokens and limits:
    - `modelWeight(model)`, `weighted(usage, model)`
    - `usageEvent(line) -> { id, at, w } | null`
    - `projection(events, reading, kind, now) -> { kind, percent, rate, runOut, atReset, resetsAt, reading, series }` (`rate` in percent per millisecond)
    - `freshestReading(sessions, kind)`
    - `limitPauses(jobs, limits, now) -> [{ kind, from, to }]`, with `jobs` as `[{ start, end }]` on the unpaused clock
    - `afterPauses(t, pauses) -> t` moved past every wait that starts before it
  - Layout:
    - `attention(session, now) -> { shape, reason }`
    - `calendarWindow(starts, ends, now) -> { from, to }`
    - `placeQueued(names, openEnds, typical, now)`
  - Assembly: `buildSnapshot(input) -> snapshot`.

    `input` is `{ now, project, sessions, registry, workstreams, history, events, merges, releases, queued }`, where `workstreams[name]` is `{ worktreeMissing? , planPath?, planMd?, versions?, commits? }`.

    The snapshot is `{ v: 1, project, builtAt, staleSince, limits: { fiveHour, week }, pauses, window, rows, queued, rollout: { merges, releases, projected }, etaBasis }`. Every estimated task time, row `end` and queued `start` and `end` is already moved past `pauses`.

// Pure functions for the liveview snapshot: parsing, timing, ETA, tokens, projection, rollout. No I/O.

export const MIN = 60_000
export const HOUR = 60 * MIN
export const DAY = 24 * HOUR
export const GAP_CAP_MIN = 120
export const DEFAULT_TASK_MIN = 45
export const DEFAULT_WORKSTREAM_MIN = 2 * 24 * 60
export const STALE_MS = 30 * MIN
export const BIG_CONTEXT = 250_000

const cells = line => line.trim().replace(/^\||\|$/g, '').split('|').map(c => c.trim())
const ticks = s => [...s.matchAll(/`([^`]+)`/g)].map(m => m[1])

// `.orchestra/workstreams.md` rows: name, session, branch, worktree, stage.
export function parseRegistry(md) {
  const rows = []
  for (const line of md.split(/\r?\n/)) {
    if (!line.trim().startsWith('|')) continue
    const c = cells(line)
    if (c.length < 7 || c[0] === 'Workstream' || /^-+$/.test(c[0])) continue
    const [branch = '', worktree = ''] = ticks(c[2])
    rows.push({ name: c[0], session: c[1], branch, worktree: worktree.replace(/\\/g, '/'), stage: c[6] })
  }
  return rows
}

// The handoff note's "Plan: `docs/superpowers/plans/<plan>.md`, task N" line.
export function planPathFromNote(note) {
  return /^Plan:\s*`([^`]+)`/m.exec(note ?? '')?.[1] ?? null
}

// Plan tasks: `### Task N: title`, the `**Agent:** x. **Risk:** y.` line and the step checkboxes.
export function parsePlan(md) {
  const tasks = []
  let t = null
  for (const line of md.split(/\r?\n/)) {
    const h = /^###\s+Task\s+(\d+):\s*(.+?)\s*$/.exec(line)
    if (h) {
      t = { n: Number(h[1]), title: h[2], agent: '', risk: '', steps: 0, ticked: 0 }
      tasks.push(t)
      continue
    }
    if (!t) continue
    if (/^##\s/.test(line)) { t = null; continue }
    const agent = /\*\*Agent:\*\*\s*`?([\w-]+)`?/.exec(line)
    if (agent && !t.agent) t.agent = agent[1]
    const risk = /\*\*Risk:\*\*\s*`?([\w-]+)`?/.exec(line)
    if (risk && !t.risk) t.risk = risk[1]
    const box = /^\s*- \[([ xX])\]/.exec(line)
    if (box) { t.steps++; if (box[1] !== ' ') t.ticked++ }
  }
  return tasks.map(({ ticked, ...x }) => ({ ...x, done: x.steps > 0 && ticked === x.steps }))
}

// "Project settings" in CLAUDE.md: the integration and production branch names.
export function parseBranches(claudeMd) {
  const pick = re => re.exec(claudeMd ?? '')?.[1]?.replace(/^<|>$/g, '') ?? null
  return {
    integration: pick(/Integration branch[^`\n]*`([^`]+)`/),
    production: pick(/Production branch[^`\n]*`([^`]+)`/),
  }
}

// "Next workstreams" in docs/HANDOFF.md: "1. <name>: <one line>".
export function parseQueued(handoff) {
  const section = /^## Next workstreams\s*$([\s\S]*?)(?=^## |(?![\s\S]))/m.exec(handoff ?? '')?.[1] ?? ''
  return [...section.matchAll(/^\s*\d+\.\s*([^:\n]+?)\s*:/gm)].map(m => m[1]).filter(n => !n.startsWith('<'))
}

export function median(xs) {
  if (xs.length === 0) return null
  const s = [...xs].sort((a, b) => a - b)
  const m = s.length >> 1
  return s.length % 2 ? s[m] : (s[m - 1] + s[m]) / 2
}

// Minutes between `from` and `to`, summing the gaps between the commits in between, each capped.
export function cappedMinutes(from, to, commits) {
  const points = [from, ...commits.filter(c => c > from && c < to).sort((a, b) => a - b), to]
  let total = 0
  for (let i = 1; i < points.length; i++) total += Math.min((points[i] - points[i - 1]) / MIN, GAP_CAP_MIN)
  return Math.round(total)
}

// Finished tasks of one plan, from its versions in git (oldest first) and the branch's commit times.
// shortcut: wall-clock commit gaps, not real agent time; switch to subagent transcript spans if ETAs drift.
export function timedTasks(plan, versions, commits) {
  if (versions.length === 0) return []
  const finishes = new Map()
  for (const v of versions) {
    for (const t of parsePlan(v.md)) if (t.done && !finishes.has(t.n)) finishes.set(t.n, v.at)
  }
  const latest = new Map(parsePlan(versions.at(-1).md).map(t => [t.n, t]))
  const done = [...finishes].filter(([n]) => latest.get(n)?.done).sort((a, b) => a[1] - b[1])
  let prev = versions[0].at
  return done.map(([n, at]) => {
    const t = latest.get(n)
    const row = { plan, task: n, agent: t.agent, risk: t.risk, startedAt: prev, finishedAt: at, minutes: cappedMinutes(prev, at, commits) }
    prev = at
    return row
  })
}

// Estimate for an open task: median of the closest bucket with at least 3 past tasks.
export function estimate(task, history) {
  const buckets = [
    history.filter(h => h.agent === task.agent && h.risk === task.risk),
    history.filter(h => h.agent === task.agent),
    history,
  ]
  for (const b of buckets) if (b.length >= 3) return { minutes: Math.round(median(b.map(h => h.minutes))), calibrated: true }
  return { minutes: DEFAULT_TASK_MIN, calibrated: false }
}

// Typical workstream length: median of the per-plan totals in the history.
export function typicalWorkstream(history) {
  const perPlan = new Map()
  for (const h of history) perPlan.set(h.plan, (perPlan.get(h.plan) ?? 0) + h.minutes)
  const m = median([...perPlan.values()])
  return m === null ? { minutes: DEFAULT_WORKSTREAM_MIN, calibrated: false } : { minutes: Math.round(m), calibrated: true }
}

// shortcut: price ratios as a proxy for how plans count usage; recalibrated on every reading, so only the ratios matter.
export function modelWeight(model) {
  if (/opus/i.test(model ?? '')) return 5
  if (/haiku/i.test(model ?? '')) return 1
  return 3
}

export function weighted(usage, model) {
  const u = usage ?? {}
  const raw = (u.input_tokens ?? 0) + 1.25 * (u.cache_creation_input_tokens ?? 0) + 0.1 * (u.cache_read_input_tokens ?? 0) + 5 * (u.output_tokens ?? 0)
  return raw * modelWeight(model)
}

// One transcript line to a usage event, or null. Only id, time, model and usage are read.
export function usageEvent(line) {
  let o
  try { o = JSON.parse(line) } catch { return null }
  const m = o?.message
  if (o?.type !== 'assistant' || !m?.usage || !m.id) return null
  const at = Date.parse(o.timestamp)
  return Number.isFinite(at) ? { id: m.id, at, w: weighted(m.usage, m.model) } : null
}

const WINDOWS = { five_hour: 5 * HOUR, seven_day: 7 * DAY }

// Limit projection from usage events and the freshest reading ({ kind, percentUsed, resetsAt, at }).
export function projection(events, reading, kind, now) {
  if (!reading || !reading.resetsAt) return { kind, percent: null, rate: 0, runOut: null, atReset: null, resetsAt: null, reading: null, series: [] }
  const span = WINDOWS[kind]
  const reset = Date.parse(reading.resetsAt)
  const start = reset - span
  const sum = (a, b) => events.reduce((s, e) => (e.at >= a && e.at <= b ? s + e.w : s), 0)
  const base = sum(start, reading.at)
  const k = base > 0 ? reading.percentUsed / base : null
  const percent = k === null ? reading.percentUsed : Math.round(k * sum(start, now) * 10) / 10
  const rateSpan = Math.min(DAY, span / 5)
  const rate = k === null ? 0 : (k * sum(now - rateSpan, now)) / rateSpan
  let runOut = percent >= 100 ? now : rate > 0 ? Math.round(now + (100 - percent) / rate) : null
  if (runOut !== null && runOut >= reset) runOut = null
  const series = []
  if (k !== null) {
    const step = span / 84
    for (let t = start; t <= Math.min(now, reset); t += step) series.push({ at: t, percent: Math.round(k * sum(start, t) * 10) / 10 })
  }
  const atReset = k === null ? null : Math.round((percent + rate * Math.max(0, reset - now)) * 10) / 10
  return { kind, percent, rate, runOut, atReset, resetsAt: reading.resetsAt, reading: { at: reading.at, percent: reading.percentUsed }, series }
}

// Limit pauses ahead: all work stops while a limit is spent and resumes at its reset. Jobs are { start, end } on the
// unpaused clock; the burn rate (percent per ms, from projection) scales with how many jobs are open at once.
// shortcut: today's pace held constant; a pace change shows up at the next 5-second rebuild.
export function limitPauses(jobs, limits, now) {
  const spans = jobs.map(j => ({ from: Math.max(0, j.start - now), to: Math.max(0, j.end - now) })).filter(j => j.to > j.from)
  const goal = Math.max(0, ...spans.map(j => j.to))
  const open = w => spans.filter(j => j.from <= w && w < j.to).length
  const base = open(0) || 1
  const meters = limits.filter(l => l.percent != null && l.rate > 0)
    .map(l => ({ kind: l.kind, used: l.percent, reset: Date.parse(l.resetsAt), span: WINDOWS[l.kind], rate: l.rate }))
  const edges = [...new Set(spans.flatMap(j => [j.from, j.to]))].sort((a, b) => a - b)
  const pauses = []
  let t = now, w = 0
  for (let guard = 0; w < goal && guard < 10_000; guard++) {
    for (const m of meters) if (t >= m.reset) {
      m.used = 0
      // The weekly window resets on a fixed schedule; a new 5-hour window opens with the first message after a reset.
      m.reset = m.kind === 'five_hour' ? t + m.span : m.reset + Math.ceil((t - m.reset + 1) / m.span) * m.span
    }
    const spent = meters.filter(m => m.used >= 99.999)
    if (spent.length) {
      const last = spent.reduce((a, b) => (b.reset > a.reset ? b : a))
      pauses.push({ kind: last.kind, from: t, to: last.reset })
      t = last.reset
      continue
    }
    const share = open(w) / base
    let dt = edges.find(e => e > w) - w
    for (const m of meters) {
      if (share > 0) dt = Math.min(dt, (100 - m.used) / (m.rate * share))
      dt = Math.min(dt, m.reset - t)
    }
    for (const m of meters) m.used += m.rate * share * dt
    t += dt
    w += dt
  }
  return pauses
}

// A time on the unpaused clock, pushed back by every pause that starts before it.
export const afterPauses = (t, pauses) => pauses.reduce((out, p) => (p.from < out ? out + (p.to - p.from) : out), t)

// The freshest reading of one kind across session files.
export function freshestReading(sessions, kind) {
  let best = null
  for (const s of sessions) {
    const l = (s.limits ?? []).find(x => x.kind === kind)
    const at = Date.parse(s.updatedAt)
    if (l && Number.isFinite(at) && (!best || at > best.at)) best = { ...l, at }
  }
  return best
}

// Shape and reason, with the band's rules. An outlined half circle marks what is idle by accident: stale, unregistered, no session.
export function attention(session, now) {
  if (!session) return { shape: 'half-open', reason: 'no session' }
  if (session.state === 'waiting') return { shape: 'triangle', reason: 'waiting' }
  if ((session.context?.tokens ?? 0) >= BIG_CONTEXT) return { shape: 'square', reason: 'over 250k' }
  if (now - Date.parse(session.updatedAt) > STALE_MS) return { shape: 'half-open', reason: 'stale' }
  if (session.role === 'unregistered') return { shape: 'half-open', reason: 'unregistered' }
  if (session.state === 'running') return { shape: 'circle', reason: 'running' }
  return { shape: 'half', reason: 'idle' }
}

// Calendar: from the oldest open start (at most 3 days back) to the latest end, at least one day wide.
export function calendarWindow(starts, ends, now) {
  const from = Math.max(Math.min(now, ...starts), now - 3 * DAY)
  const to = Math.max(from + DAY, now + HOUR, ...ends)
  return { from, to }
}

// The n-th queued workstream starts at the n-th earliest projected end.
export function placeQueued(names, openEnds, typical, now) {
  const ends = [...openEnds].sort((a, b) => a - b)
  return names.map((name, i) => {
    const start = ends[i] ?? ends.at(-1) ?? now
    return { name, start, end: start + typical.minutes * MIN, calibrated: typical.calibrated }
  })
}

const sessionRow = (s, now) => ({
  key: s.session, name: s.title || s.workstream || s.branch || s.session, link: /^claude:\/\//.test(s.link ?? '') ? s.link : '',
  role: s.role, state: s.state, detail: s.detail ?? '', context: s.context?.tokens ?? null, stage: s.stage ?? '', pr: s.pr ?? '',
  ...attention(s, now), plan: null, tasks: [], done: 0, total: 0, eta: null, etaCalibrated: true, start: null, end: null,
})

// Everything the page draws, from what sources.mjs gathered.
export function buildSnapshot(input) {
  const { now, project, sessions, registry, workstreams, history, events, merges, releases, queued } = input
  const rows = []
  const listed = new Set()
  for (const s of sessions.filter(s => s.role === 'maestro')) { rows.push(sessionRow(s, now)); listed.add(s.session) }
  for (const r of registry) {
    const s = sessions.find(x => x.workstream === r.name) ?? null
    if (s) listed.add(s.session)
    const row = s ? { ...sessionRow(s, now), name: s.title || r.name } : { ...sessionRow({ session: r.name, workstream: r.name, role: 'workstream', state: 'idle', updatedAt: new Date(now).toISOString() }, now), ...attention(null, now) }
    row.key = `ws:${r.name}`
    row.workstream = r.name
    if (!row.stage) row.stage = r.stage
    const w = workstreams[r.name] ?? {}
    if (w.worktreeMissing) row.detail = 'worktree missing'
    if (w.planMd) {
      row.plan = w.planPath
      const timed = new Map(timedTasks(w.planPath, w.versions ?? [], w.commits ?? []).map(t => [t.task, t]))
      let cursor = now
      let first = true
      row.tasks = parsePlan(w.planMd).map(t => {
        const real = timed.get(t.n)
        if (t.done) return { n: t.n, title: t.title, agent: t.agent, risk: t.risk, done: true, current: false, minutes: real?.minutes ?? null, estimated: false, calibrated: true, start: real?.startedAt ?? null, end: real?.finishedAt ?? null }
        const e = estimate(t, history)
        const out = { n: t.n, title: t.title, agent: t.agent, risk: t.risk, done: false, current: first, minutes: e.minutes, estimated: true, calibrated: e.calibrated, start: cursor, end: cursor + e.minutes * MIN }
        first = false
        cursor = out.end
        return out
      })
      row.done = row.tasks.filter(t => t.done).length
      row.total = row.tasks.length
      const open = row.tasks.filter(t => !t.done)
      row.eta = open.reduce((s, t) => s + t.minutes, 0)
      row.etaCalibrated = open.every(t => t.calibrated)
      row.start = w.versions?.[0]?.at ?? row.tasks.find(t => t.start)?.start ?? now
      row.end = cursor
    } else if (!w.worktreeMissing) row.detail = row.detail || 'no plan'
    rows.push(row)
  }
  for (const s of sessions.filter(s => !listed.has(s.session) && s.role === 'unregistered')) rows.push(sessionRow(s, now))

  const planned = rows.filter(r => r.end !== null)
  const typical = typicalWorkstream(history)
  const queue = placeQueued(queued, planned.map(r => r.end), typical, now)
  const limits = {
    fiveHour: projection(events, freshestReading(sessions, 'five_hour'), 'five_hour', now),
    week: projection(events, freshestReading(sessions, 'seven_day'), 'seven_day', now),
  }
  // Every estimate moves past the limit pauses, so the track, the calendar and the strip agree.
  const pauses = limitPauses([...planned.map(r => ({ start: now, end: r.end })), ...queue], [limits.fiveHour, limits.week], now)
  const shift = t => (t === null || t <= now ? t : afterPauses(t, pauses))
  for (const r of planned) {
    r.end = shift(r.end)
    for (const t of r.tasks) if (t.estimated) { t.start = shift(t.start); t.end = shift(t.end) }
  }
  for (const q of queue) { q.start = shift(q.start); q.end = shift(q.end) }
  const window = calendarWindow(planned.map(r => r.start), [...planned.map(r => r.end), ...queue.map(q => q.end)], now)
  const inWindow = xs => xs.filter(x => x.at >= window.from && x.at <= window.to)
  return {
    v: 1, project, builtAt: now, staleSince: null,
    limits, pauses,
    window, rows, queued: queue,
    rollout: { merges: inWindow(merges), releases: inWindow(releases), projected: planned.map(r => ({ name: r.name, at: r.end })) },
    etaBasis: history.length,
  }
}

import fs from 'node:fs'
import os from 'node:os'
import path from 'node:path'

export function readText(file) {
  try { return fs.readFileSync(file, 'utf8') } catch { return null }

// git output, or null when git is missing or the command fails.
export function git(cwd, args) {
  try {
    return execFileSync('git', args, { cwd, encoding: 'utf8', stdio: ['ignore', 'pipe', 'ignore'], maxBuffer: 64 * 1024 * 1024, windowsHide: true })
  } catch {
    return null
  }

// Session files with the band's format. A file that fails to parse keeps its last good reading.
const lastGood = new Map()
export function readSessions(main) {
  const dir = path.join(main, '.orchestra', 'sessions')
  let names = []
  try { names = fs.readdirSync(dir).filter(n => n.endsWith('.json')) } catch { return [] }
  const out = []
  for (const n of names) {
    try {
      const s = JSON.parse(fs.readFileSync(path.join(dir, n), 'utf8'))
      if (s?.v !== 1) continue
      lastGood.set(n, s)
      out.push(s)
    } catch {
      if (lastGood.has(n)) out.push(lastGood.get(n))
    }
  }
  return out
}

// Versions of a plan file on a ref, oldest first.
export function planVersions(cwd, ref, planPath) {
  const log = git(cwd, ['log', '--format=%H %ct', ref, '--', planPath])
  if (!log) return []
  return log.trim().split('\n').filter(Boolean).reverse().flatMap(line => {
    const [sha, ct] = line.split(' ')
    const md = git(cwd, ['show', `${sha}:${planPath}`])
    return md === null ? [] : [{ at: Number(ct) * 1000, md }]
  })
}

export function commitTimes(cwd, refArgs) {
  const log = git(cwd, ['log', '--format=%ct', ...refArgs])
  return log ? log.trim().split('\n').filter(Boolean).map(s => Number(s) * 1000) : []
}

// First-parent commits on a branch since a time: merges on the integration branch, releases on production.
export function firstParent(cwd, branch, since) {
  if (!branch) return []
  const log = git(cwd, ['log', '--first-parent', `--since=${Math.floor(since / 1000)}`, '--format=%ct%x09%s', branch])
  return log ? log.trim().split('\n').filter(Boolean).map(l => { const [ct, ...s] = l.split('\t'); return { at: Number(ct) * 1000, subject: s.join('\t') } }) : []
}

// Which plan a workstream follows: its note's Plan line, else the one plan file its branch adds.
export function findPlan(worktree, name, integration) {
  const fromNote = planPathFromNote(readText(path.join(worktree, 'docs', 'workstreams', `${name}.md`)))
  if (fromNote) return fromNote
  for (const base of integration ? [`origin/${integration}`, integration] : []) {
    const added = git(worktree, ['diff', '--name-only', '--diff-filter=A', `${base}...HEAD`, '--', PLANS])
    if (added === null) continue
    const files = added.trim().split('\n').filter(f => f.endsWith('.md'))
    return files.length === 1 ? files[0] : null
  }
  return null
}

// Per-worktree git results, reused while HEAD does not move.
const wsCache = new Map()
export function readWorkstream(row, integration) {
  if (!row.worktree || !fs.existsSync(row.worktree)) return { worktreeMissing: true }
  const planPath = findPlan(row.worktree, row.name, integration)
  const planMd = planPath ? readText(path.join(row.worktree, planPath)) : null
  if (!planPath || planMd === null || parsePlan(planMd).length === 0) return {}
  const head = git(row.worktree, ['rev-parse', 'HEAD'])?.trim() ?? ''
  const key = `${row.worktree}|${planPath}`
  const cached = wsCache.get(key)
  if (cached && cached.head === head && head) return { planPath, planMd, versions: cached.versions, commits: cached.commits }
  const versions = planVersions(row.worktree, 'HEAD', planPath)
  const since = versions[0]?.at ?? Date.now() - 30 * DAY
  const commits = commitTimes(row.worktree, [`--since=${Math.floor(since / 1000)}`, 'HEAD'])
  wsCache.set(key, { head, versions, commits })
  return { planPath, planMd, versions, commits }
}

// The ETA history: one JSON line per finished task, keyed by plan and task.
export function readHistory(main) {
  const text = readText(path.join(main, '.orchestra', 'eta-history.jsonl')) ?? ''
  const seen = new Map()
  for (const line of text.split('\n')) {
    try { const h = JSON.parse(line); seen.set(`${h.plan}#${h.task}`, h) } catch { /* a torn last line */ }
  }
  return [...seen.values()]
}

export function appendHistory(main, history, entries) {
  const known = new Set(history.map(h => `${h.plan}#${h.task}`))
  const fresh = entries.filter(e => !known.has(`${e.plan}#${e.task}`))
  if (fresh.length === 0) return history
  const lines = fresh.map(({ plan, task, agent, risk, minutes, finishedAt }) => JSON.stringify({ plan, task, agent, risk, minutes, finishedAt }))
  fs.appendFileSync(path.join(main, '.orchestra', 'eta-history.jsonl'), `${lines.join('\n')}\n`)
  return [...history, ...fresh]
}

// Seeds the history from every plan file anywhere in the repository's history.
export function seedHistory(main) {
  const names = git(main, ['log', '--all', '--name-only', '--format=', '--', PLANS])
  const plans = [...new Set((names ?? '').split('\n').filter(f => f.endsWith('.md')))]
  return plans.flatMap(p => {
    const versions = planVersions(main, '--all', p)
    if (versions.length === 0) return []
    return timedTasks(p, versions, commitTimes(main, ['--all', `--since=${Math.floor(versions[0].at / 1000)}`]))
  })
}

// Reads Claude Code transcripts incrementally: only the bytes appended since the last pass.
export class TranscriptReader {
  constructor(dir = path.join(process.env.CLAUDE_CONFIG_DIR || path.join(os.homedir(), '.claude'), 'projects')) {
    this.dir = dir
    this.files = new Map()
    this.events = new Map()
  }

  scan(now) {
    for (const file of this.list(this.dir, now - 8 * DAY)) this.readFile(file)
    for (const [id, e] of this.events) if (e.at < now - 8 * DAY) this.events.delete(id)
    return [...this.events.values()]
  }

  list(dir, since) {
    let entries = []
    try { entries = fs.readdirSync(dir, { withFileTypes: true }) } catch { return [] }
    return entries.flatMap(e => {
      const p = path.join(dir, e.name)
      if (e.isDirectory()) return this.list(p, since)
      if (!e.name.endsWith('.jsonl')) return []
      try { return fs.statSync(p).mtimeMs >= since ? [p] : [] } catch { return [] }
    })
  }

  readFile(file) {
    let size
    try { size = fs.statSync(file).size } catch { return }
    let st = this.files.get(file) ?? { offset: 0, rest: '' }
    if (size < st.offset) st = { offset: 0, rest: '' }
    if (size === st.offset) return
    const fd = fs.openSync(file, 'r')
    try {
      const buf = Buffer.alloc(size - st.offset)
      fs.readSync(fd, buf, 0, buf.length, st.offset)
      const lines = (st.rest + buf.toString('utf8')).split('\n')
      st = { offset: size, rest: lines.pop() ?? '' }
      for (const line of lines) {
        const e = line.includes('"usage"') ? usageEvent(line) : null
        if (e) this.events.set(e.id, e)
      }
    } finally {
      fs.closeSync(fd)
      this.files.set(file, st)
    }
  }
}

  const registry = parseRegistry(readText(path.join(main, '.orchestra', 'workstreams.md')) ?? '')

  return {

    project: path.basename(main),
    sessions: readSessions(main),
    registry,
    workstreams,
    history,
    events: reader.scan(now),
    merges: firstParent(main, integration, since),
    releases: firstParent(main, production, since),
    queued: parseQueued(readText(path.join(main, 'docs', 'HANDOFF.md'))),
  }
}

// orchestra liveview: a local page for one project. Reads files on disk only; uses no LLM tokens.
//   node server.mjs --root <main checkout>            run in the foreground
//   node server.mjs --root <main checkout> --detach   start in the background, print the URL

import fs from 'node:fs'

import { MIN, buildSnapshot, timedTasks } from './snapshot.mjs'

export const FIRST_PORT = 4317
export const PORT_TRIES = 21
export const TICK_MS = 5000
export const IDLE_MS = 30 * MIN

const infoFile = root => path.join(root, '.orchestra', 'liveview.json')

function readInfo(root) {
  try { return JSON.parse(fs.readFileSync(infoFile(root), 'utf8')) } catch { return null }
}

// The URL of a live server for this root, or null.
export async function liveUrl(root) {
  const info = readInfo(root)
  if (!info?.url) return null
  try {
    const r = await fetch(new URL('api/ping', info.url), { signal: AbortSignal.timeout(1000) })
    const body = await r.json()
    return path.resolve(body.root) === path.resolve(root) ? info.url : null
  } catch {
    return null
  }
}

function listen(server, port, last) {
  return new Promise((resolve, reject) => {
    const onError = err => {
      server.off('listening', onListening)
      if (err.code === 'EADDRINUSE' && port < last) resolve(listen(server, port + 1, last))
      else reject(err)
    }
    const onListening = () => { server.off('error', onError); resolve(port) }
    server.once('error', onError)
    server.once('listening', onListening)
    server.listen(port, '127.0.0.1')
  })
}

// Starts the server. Options exist for tests: port, clock, tick, idle limit, transcript folder, idle action.
export async function startServer({
  root, port = FIRST_PORT, now = Date.now, tickMs = TICK_MS, idleMs = IDLE_MS,
  reader = new TranscriptReader(), onIdle = () => process.exit(0), auto = true,
}) {
  root = path.resolve(root)
  const page = fs.readFileSync(path.join(HERE, 'page.html'))
  const startedAt = now()
  let history = appendHistory(root, readHistory(root), seedHistory(root))
  let snapshot = null
  let bound = 0
  let idle = false

  const tick = () => {
    try {
      const input = gather(root, now(), reader, history)
      const live = Object.values(input.workstreams).flatMap(w => (w.versions ? timedTasks(w.planPath, w.versions, w.commits) : []))
      history = appendHistory(root, history, live)
      input.history = history
      snapshot = buildSnapshot(input)
    } catch (err) {
      if (snapshot) snapshot.staleSince ??= now()
      else snapshot = { v: 1, error: String(err?.message ?? err), staleSince: now(), rows: [] }
    }
    const fresh = readSessions(root).some(s => now() - Date.parse(s.updatedAt) < idleMs)
    if (!idle && now() - startedAt >= idleMs && !fresh) {
      idle = true
      void close().then(onIdle)
    }
  }

  const server = http.createServer((req, res) => {
    const host = req.headers.host ?? ''
    if (host !== `localhost:${bound}` && host !== `127.0.0.1:${bound}`) {
      res.writeHead(403).end('forbidden')
      return
    }
    const send = (type, body) => res.writeHead(200, { 'content-type': type, 'cache-control': 'no-store' }).end(body)
    const route = new URL(req.url ?? '/', 'http://localhost').pathname
    if (req.method !== 'GET') res.writeHead(405).end()
    else if (route === '/') send('text/html; charset=utf-8', page)
    else if (route === '/api/snapshot') send('application/json', JSON.stringify(snapshot))
    else if (route === '/api/ping') send('application/json', JSON.stringify({ root }))
    else res.writeHead(404).end('not found')
  })

  bound = await listen(server, port, port + PORT_TRIES - 1)
  const url = `http://localhost:${bound}/`
  fs.mkdirSync(path.join(root, '.orchestra'), { recursive: true })
  fs.writeFileSync(infoFile(root), JSON.stringify({ url, pid: process.pid }))
  let timer = null
  const close = () => {
    if (timer) clearInterval(timer)
    if (readInfo(root)?.url === url) fs.rmSync(infoFile(root), { force: true })
    return new Promise(resolve => server.close(() => resolve()))
  }
  tick()
  if (auto) timer = setInterval(tick, tickMs)
  return { url, port: bound, tick, close }
}

// Stops the server recorded in liveview.json. On Windows the signal cannot run our handler, so the file goes here.
export function stop(root) {
  const info = readInfo(root)
  if (info?.pid) { try { process.kill(info.pid) } catch { /* already gone */ } }
  fs.rmSync(infoFile(root), { force: true })
}

async function main(argv) {
  const arg = name => { const i = argv.indexOf(name); return i >= 0 ? argv[i + 1] : undefined }
  const root = path.resolve(arg('--root') ?? process.cwd())
  if (argv.includes('--stop')) { stop(root); console.log('liveview stopped'); return }
  const running = await liveUrl(root)
  if (running) { console.log(running); return }
  if (argv.includes('--detach')) {
    spawn(process.execPath, [fileURLToPath(import.meta.url), '--root', root], { detached: true, stdio: 'ignore', windowsHide: true }).unref()
    for (let i = 0; i < 50; i++) {
      await new Promise(r => setTimeout(r, 100))
      const url = await liveUrl(root)
      if (url) { console.log(url); return }
    }
    console.error('liveview did not start')
    process.exitCode = 1
    return
  }
  let s
  try {
    s = await startServer({ root })
  } catch (err) {
    console.error(`liveview: no free port from ${FIRST_PORT} to ${FIRST_PORT + PORT_TRIES - 1} (${err.code ?? err})`)
    process.exit(1)
  }
  console.log(s.url)
  const quit = () => s.close().then(() => process.exit(0))
  process.on('SIGINT', quit)
  process.on('SIGTERM', quit)
}

if (process.argv[1] && import.meta.url === pathToFileURL(path.resolve(process.argv[1])).href) await main(process.argv.slice(2))

  // Labels stay inside the track; midnight names the day; the now line is labelled.

// One rounded pill per workstream: the planned span as a tint, the done part solid.
function marks(r, pos, width) {
  const done = r.tasks.filter(t => t.done && t.start != null && t.end != null)
  const all = r.tasks.filter(t => t.start != null && t.end != null)
  if (!all.length) return []
  const start = Math.min(...all.map(t => t.start)), end = Math.max(...all.map(t => t.end))
  const doneEnd = done.length ? Math.max(...done.map(t => t.end)) : null
  const title = `${r.done} of ${r.total} done, ${dur(r.eta)} left`
  return [
    $('span', { class: 'pill', style: `left:${pos(start)};width:${width(start, end)};background:var(--data-tint)`, title }),
    doneEnd ? $('span', { class: 'pill', style: `left:${pos(start)};width:${width(start, doneEnd)};background:var(--data)`, title }) : null,
  ]
}

  $('svg:polygon', { points: '6,0.5 11.5,6 6,11.5 0.5,6', fill: 'var(--surface)', stroke: q ? 'var(--muted)' : 'var(--text)', 'stroke-dasharray': q ? '2 2' : null }))

function calendar(snap) {
  const drops = [...snap.rows.filter(r => r.end != null).map(r => ({ name: r.name, at: r.end, queued: false })), ...snap.queued.map(q => ({ name: q.name, at: q.end, queued: true }))].sort((a, b) => a.at - b.at)
  const box = document.getElementById('cal')
  const waits = waitMs(snap, snap.builtAt, Infinity)
  document.getElementById('cal-meta').textContent = drops.length ? `At today's pace${waits ? `, with ${dur(Math.round(waits / MIN))} of limit waits` : ''}` : ''
  if (!drops.length) { box.replaceChildren($('p', { class: 'meta', style: 'margin:0' }, 'No plan is open, so nothing is due.')); return }
  const today = dayStart(snap.builtAt), lastDay = dayStart(drops.at(-1).at)
  const on = d => drops.filter(x => x.at >= d && x.at < addDays(d, 1))
  const drop = x => $('div', { class: 'drop' }, dropMark(x.queued), $('b', {}, x.name), $('span', { class: 'meta' }, clock(x.at)))
  const first = addDays(today, -((new Date(today).getDay() + 6) % 7))
  const end = addDays(lastDay, 7 - ((new Date(lastDay).getDay() + 6) % 7))
  const cells = []
  for (let i = 0; i < 7; i++) cells.push($('div', { class: 'dow' }, new Date(addDays(first, i)).toLocaleDateString(undefined, { weekday: 'short' })))
  for (let d = first; d < end; d = addDays(d, 1)) {
    const its = on(d), from = Math.max(d, snap.builtAt), wait = waitMs(snap, from, addDays(d, 1))
    const blocked = wait > 0 && wait >= addDays(d, 1) - from - MIN
    const dt = new Date(d)
    cells.push($('div', { class: `cell${d < today ? ' past' : ''}${d === today ? ' today' : ''}${blocked ? ' blocked' : ''}${!its.length && !wait ? ' empty' : ''}` },
      $('span', { class: 'num', 'aria-label': dt.toLocaleDateString(undefined, { weekday: 'long', day: 'numeric', month: 'long' }) },
        dt.getDate() === 1 || d === first ? dt.toLocaleDateString(undefined, { day: 'numeric', month: 'short' }) : String(dt.getDate())),
      its.map(drop),
      wait ? $('span', { class: 'note' }, blocked ? 'Limit spent: no work' : `${dur(Math.round(wait / MIN))} limit wait`) : null))
  }
  box.replaceChildren($('div', { class: 'month' }, cells))
}

}
